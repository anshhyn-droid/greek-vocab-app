# 문장 학습 명세 (제3과 · 웹/폰 반응형)

참고 화면: `Sentence Study.dc.html` · 데이터: `sentences_l03.json` (엑셀 `sentences` 9문장 + `sentence_parsing` 동사 10개)

> **변경 (최신)**
> - 헤더의 문항 수(1 / 9)는 없습니다
> - 헬라어 글꼴은 Noto Serif(다중 강세 부호 지원)
> - **확인 버튼은 맨 아래 하나**입니다. 해석 칸에 낱말이 1개 이상 있고, 모든 동사 파싱(원형~인칭)을 마쳤을 때만 눌립니다. 해석 낱말 개수는 상관없습니다
> - 확인 시: 틀린 낱말은 빼고 잠금, 모자라면 "낱말 N개가 더 필요합니다" 안내. 둘 다 오답으로 쳐서 그 문장은 마지막에 다시 나옵니다
> - 파싱에서 정답을 고르면 정답은 초록, 나머지 보기는 흐려지지 않고 그대로 둡니다
> - **파싱은 먼저 고르기만** 합니다. 고른 보기는 기본색보다 한 단계 진한 중립색(neutral-200 바탕 · neutral-500 테두리)으로 표시하고, 다시 누르면 선택이 풀립니다. 정답(초록)·오답(빨강)은 **확인을 누른 뒤에** 보여줍니다. 맞은 칸은 잠기고, 틀린 보기는 빨갛게 잠긴 채 다시 고르게 합니다
> - 낱말 블록을 끌 때 해석 칸도 같은 중립색으로 표시합니다
> - 문장 진행 동그라미는 데이터 번호가 아니라 **학습자가 푼 순서**대로 1번부터 채웁니다(한 번에 맞힘 초록 · 틀렸다 맞힘 빨강 · 지금 주황)
> - 헤더: "처음부터" 버튼과 설정 XP 배지는 없습니다. "해석과 동사 파싱을 모두 맞히면 다음 문장으로 넘어갑니다" 안내는 제목 "연습 문장" 옆에 둡니다
> - 낱말을 끌어 해석 칸에 놓으면 **놓은 위치에 끼워 넣습니다**. 끄는 동안 들어갈 자리가 벌어져 보이고, 해석 칸 안에서 끌면 순서만 바뀝니다
> - 확인 뒤 틀린 파싱 보기는 빨강으로 보여주고, 그 칸에서 다른 보기를 고르면 회색으로 바뀌어 다시 누를 수 없습니다
> - 완료 모션(세 학습 공통): 오른쪽 위에 "총 경험치" 배지가 내려오고, 결과 카드의 "+N XP"가 날아가 박히며 숫자가 합산된 뒤 약 2초 후 사라집니다 (`xp-fly.js`)
> - 낱말 블록은 누르거나 끌어다 넣고, 해석 칸 밖으로 끌어내 뺄 수 있습니다

> **출제 방식**: 문장은 매번 무작위 순서로 나옵니다.

## 1. 데이터

**sentences 시트**: example_id, 번호, 문장(헬라어), 정답_번역, 비고
- 새로 추가할 열 **오답_블록**(선택): 함정 낱말을 쉼표로 적습니다. 값이 있으면 자동 규칙 대신 이 값을 씁니다

**sentence_parsing 시트**: sentence_id로 문장에 연결합니다. 형태, 기본형, 뜻, 시제_id, 태_id, 법_id, 수_id, 인칭_id, 해석
- 한 문장에 동사가 여러 개면(E308) 파싱 카드도 여러 개 나옵니다

## 2. 한 문장 화면

위에서부터:
1. 태그 "제3과 N번 문장"(N = 번호 열), 다시 푸는 문장이면 "다시 풀기" 태그
2. 헬라어 문장 (크게)
3. **해석 블록 맞추기**
4. **동사 파싱** (동사마다 카드 1개)
5. 모두 맞히면: 비고 설명(있을 때만) + "다음 문장" 버튼

3과 4는 어느 것부터 풀어도 됩니다.

## 3. 해석 블록

- 정답_번역을 띄어쓰기로 나눈 낱말 + 함정 낱말 2~3개를 섞어서 보여줍니다. 문장부호는 뺍니다
- 블록을 누르면 입력 줄에 들어가고, 입력 줄의 블록을 누르면 빠집니다. "지우기"는 전부 뺍니다
- **어순은 보지 않습니다.** 정답 낱말이 모두 들어가고 함정이 없으면 정답입니다
- "확인"은 정답 낱말 수만큼 넣었을 때만 누를 수 있습니다
- 틀리면 함정 블록만 빠지고 취소선과 함께 잠깁니다. 맞게 넣은 블록은 남습니다

**함정 자동 규칙** (오답_블록이 비어 있을 때, 서버에서 만듦)
| 종류 | 방법 | 예 |
|---|---|---|
| 인칭 | 대명사 주어를 다른 인칭으로 | 나는 → 그들은 |
| 격 | 명사 조사를 바꿈 (받침에 따라 을/를, 이/가, 은/는) | 여주인을 → 여주인이 |
| 동사 · 시제 | 과거·미래로 | 말한다 → 말했다, 말하겠다 |
| 동사 · 법 | 명령형으로 | 말한다 → 말하라 |
| 동사 · 태 | 수동으로 | 듣는다 → 들린다 |
| 동사 · 문형 | 평서 ↔ 의문 | 가르치는가 → 가르친다 |

인칭·격 함정 최대 2개 + 동사 함정 후보 5개 중 무작위 3개. 동사 함정 후보는 문장마다 준비합니다(예시는 `sentences_l03.json`의 `koVerbTraps`).

정답 낱말과 같은 함정은 넣지 않습니다.

## 4. 동사 파싱

| 축 | 선택지 (코드) |
|---|---|
| 원형 | 같은 동사의 변화형 4개 중 기본형(1인칭 단수) 고르기. 오답 = 문장 속 형태 + 다른 인칭·수 형태 (예: λύω · λύει · λύομεν · λύουσι) |
| 시제 | 현재 PRES · 미완료과거 IMPF · 미래 FUT · 부정과거 AOR |
| 태 | 능동 ACT · 중간 MID · 수동 PASS |
| 법 | 직설법 IND · 가정법 SUBJ · 명령법 IMPV |
| 수 | 단수 S · 복수 P |
| 인칭 | 1인칭 1p · 2인칭 2p · 3인칭 3p |

- 여섯 줄(원형·시제·태·법·수·인칭)이 모두 열려 있고 순서 제한이 없습니다
- 카드 제목에는 동사 형태만 보이고, 원형을 맞히면 "← 기본형 · 뜻"이 나타납니다
- 오답은 회색(45%)으로 잠기고, 정답은 초록색이 됩니다. 그 줄의 나머지 선택지는 흐려집니다
- 여섯 줄을 모두 맞히면 그 동사의 해석이 나옵니다
