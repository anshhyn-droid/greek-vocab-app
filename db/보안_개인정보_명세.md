# 보안 · 개인정보 명세

참고 시안: `Start.dc.html`(약관 동의 · 마이페이지 · 탈퇴), `gk-session.js`(자동 로그아웃), `Word Study.dc.html`(즐겨찾기 즉시 저장).
처리방침·약관 문안은 임시입니다. 실제 문서가 정해지면 교체합니다.

## 1. 가입과 동의
| 항목 | 결정 |
|---|---|
| 언제 | 새 사용자의 첫 로그인 때만. Google 계정 선택 → 약관 동의 → 가입 |
| 필수 | 만 14세 이상 · 이용약관 · 개인정보 수집·이용(항목: 이름, 이메일, 학습 기록 / 목적: 계정 확인, 학습 기록 저장·동기화 / 보유: 탈퇴 시 바로 삭제) |
| 선택 | 없음 (학습 알림은 출시 범위에서 제외. 알림을 만들 때 선택 동의 항목으로 다시 추가) |
| 버튼 | 필수를 모두 체크해야 "동의하고 시작하기"가 켜짐. "모두 동의"로 한 번에 |
| 저장 | [DB] `user_consents`(user_id, type, agreed, version, agreed_at). 약관 버전이 바뀌면 다음 로그인 때 다시 받음 |
| Google에서 받는 것 | 이름·이메일만 저장. 프로필 사진은 저장하지 않음(화면은 이름 첫 글자) |
| 화면 표시 | 마이페이지의 이메일은 앞 두 글자만 (yo*******@gmail.com) |
| 문서 | 마이페이지 > 개인정보에서 처리방침·이용약관 열람 |

## 2. 자동 로그아웃
| 항목 | 결정 |
|---|---|
| 기한 | 하루(24시간) 동안 사용하지 않으면 로그아웃. 사용자 설정 없음 |
| 판단 | 서버. 세션 쿠키 만료를 24시간으로 두고 요청이 올 때마다 연장. 화면은 안내만 |
| 안내 | 남은 시간이 1분이면 안내 창: "곧 자동으로 로그아웃됩니다 · N초 뒤 로그아웃됩니다. 풀던 문제는 저장되지 않습니다." 버튼 **계속 사용하기** / 로그아웃 |
| 로그아웃 뒤 | 시작 화면 위쪽 안내: "하루 동안 사용하지 않아 자동으로 로그아웃되었습니다. 다시 로그인해 주세요." |
| 여러 탭 | 한 탭에서 움직이면 다른 탭도 연장 |
| 절대 만료 | 계속 사용해도 로그인 후 30일이 지나면 다시 로그인 |
| 시연 | 시안 Start의 Tweaks에서 idleDemo를 켜면 하루 대신 40초 |

## 3. 회원 탈퇴
- 위치: 마이페이지 맨 아래 "회원 탈퇴"
- 확인 창: 지워지는 것(학습 기록·경험치, 오답 노트·즐겨찾기, 설정) · 되돌릴 수 없음 · 같은 계정으로 다시 가입하면 처음부터 · "안내를 확인했고 탈퇴합니다"를 체크해야 **탈퇴하기**가 켜짐
- 서버: 한 트랜잭션으로 `users`와 연결된 모든 행 삭제(테이블 목록은 `사용자_DB.xlsx`). `access_logs`만 user_id를 비우고 3개월 보관 후 삭제
- 세션·토큰 모두 폐기, Google 연결 토큰 해제
- 끝나면 시작 화면에 "탈퇴가 완료되었습니다. 계정과 학습 기록이 모두 삭제되었습니다."

## 4. 오늘의 목표 — 매일 초기화 확인
- 시안: 오늘 날짜(기기 시간대)의 학습 기록만 더하므로 자정이 지나면 0부터 다시 셉니다. 목표 카드에 "매일 자정에 0부터 다시 셉니다" 표시
- 실제: `daily_activity`를 사용자 시간대(`user_settings.timezone`) 기준 날짜로 나누고, 날짜는 서버가 정함. 기기 시계를 바꿔도 영향 없음
- 지금은 단어·문법·문장 **학습**만 목표에 들어가고 테스트 탭 결과는 들어가지 않음 (목표가 종류별이라서). 넣을지 결정 필요

## 5. 즐겨찾기
- 별을 누르는 즉시 저장(`POST/DELETE /favorites`). 학습 중간에 나가도 남음. 시안은 `gk_favs`에 즉시 저장

## 6. 보안 점검
1. **브라우저 저장 금지**: 시안은 사용자·경험치·오답을 localStorage에 둠. 실제는 모두 서버 DB, 브라우저에는 HttpOnly · Secure · SameSite=Lax 세션 쿠키만. 토큰을 localStorage에 두지 않음
2. **Google 로그인**: state와 PKCE 검증, ID 토큰의 서명·aud·iss·exp를 서버에서 확인, 리다이렉트 주소 고정
3. **점수·보상 조작 방지**: 경험치는 서버가 계산(클라이언트 값 무시). 채점도 서버에서 — 정답을 문제와 함께 내려주지 않고, 제출을 받아 서버가 판정. 짧은 시간에 몰린 완료 요청은 제한
4. **남의 데이터 접근 차단**: 모든 API는 세션의 user_id로만 조회·수정. 다른 사용자 id를 요청값으로 받지 않음
5. **입력 검증**: 이름 1~20자, 제어 문자 제거, 화면에 낼 때 이스케이프
6. **CSRF**: 상태를 바꾸는 요청은 POST + SameSite 쿠키 + CSRF 토큰
7. **전송·헤더**: HTTPS만 + HSTS. CSP(자체 스크립트와 꼭 필요한 곳만), X-Content-Type-Options, frame-ancestors 'none'
8. **외부 스크립트**: 시안은 unpkg의 `lucide@latest`를 불러옴. 실제는 버전을 고정해 자체 번들에 포함
9. **비밀값**: OAuth 비밀키·DB 비밀번호는 서버 환경 변수. 저장소에 올리지 않음
10. **로그**: 접속 기록에 이메일 등 개인정보를 평문으로 남기지 않음, 3개월 후 삭제. 관리자 DB 접근은 기록
11. **되돌릴 수 없는 작업**(학습 기록 초기화·탈퇴): 서버에서도 확인. 로그인한 지 오래됐으면 다시 로그인 요구
12. **백업**: 암호화해 보관, DB 계정은 필요한 권한만
