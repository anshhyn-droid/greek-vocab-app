# 문법 학습 명세 (제3과 · 웹)

참고 화면: `Grammar Study.dc.html`. 문제 데이터: `grammar_l03.json` (엑셀 `grammar_questions` 시트에서 뽑은 38문항)

## 1. 데이터 (grammar_questions 시트)

| 열 | 쓰임 |
|---|---|
| question_id | 문항 ID (GQ301…) |
| lesson_id | 과 (L03) |
| prompt | 문제 문장 |
| target_form | 문항 위 태그. 무엇을 묻는지 (예: 태, λύει, -ομεν) |
| option_1 ~ option_4 | 보기 |
| correct_option | 정답 번호 (1~4, **엑셀 기준**) |
| explanation | 정답을 고른 뒤 보여줄 해설 |
| source_page | 해설 옆 "교재 N쪽" |
| 난이도 | 상 / 중 / 하 태그 |
| note | 화면에 안 씀 |

- 빈 보기(option이 비어 있음)는 화면에서 뺍니다

## 2. 흐름

1. 엑셀 순서대로 한 문제씩 냅니다 (문제 순서는 섞지 않음)
2. 보기 순서는 문제가 나올 때마다 섞습니다
3. 모든 문제를 맞히면 결과 카드를 보여줍니다

## 3. 퀴즈 규칙

| 상황 | 동작 |
|---|---|
| 오답 선택 | 0.5초 동안 빨간색으로 깜빡인 뒤 회색(45%)으로 잠김. 다시 누를 수 없음 |
| 정답 선택 | 초록 테두리와 ○ 표시. 해설 박스와 "다음 문제" 버튼 표시 |
| 해설 제목 | 한 번에 맞히면 "정답이에요", 틀린 뒤 맞히면 "정답은 N번입니다" |
| N번 | **화면에 보이는 번호**. 보기를 섞었으므로 엑셀의 correct_option이 아님 |
| 한 번이라도 틀림 | 그 문제를 맨 뒤로 보내 다시 냄. "다시 풀기" 태그 표시 |
| 마지막 문제 | 버튼 문구가 "결과 보기"로 바뀜 |

키보드: 1~4 = 화면 번호 보기 선택, Enter = 다음 문제

## 4. 화면 구성 (웹)

- 전체 폭 최대 1080px, 가운데 정렬
- 위: 과 이름, 제목, "N / 38" 배지, 처음부터 버튼, 진행 막대
- 왼쪽(넓게): 문제 카드 → 보기(가로 폭에 따라 2열 또는 1열) → 해설 → 다음 버튼
- 오른쪽(300px): 문항 진행표(점 38개), 풀이 방법 안내
  - 점 색: 초록 = 한 번에 맞힘, 빨강 = 다시 푼 문제, 주황 = 지금 문제, 빈 원 = 아직
- 창이 좁으면(약 820px 이하) 오른쪽 칸이 문제 아래로 내려감

## 5. 결과 카드

| 항목 | 계산 |
|---|---|
| 한 번에 맞힘 | 한 번에 맞힌 문제 수 ÷ 전체 문제 수 |
| 소요 시간 | 시작부터 끝까지 → m:ss |
| 획득 XP | 전체 문제 수 × 3, 90% 이상이면 +10 |
| 다시 볼 항목 | 틀렸던 문제의 target_form 목록 |
