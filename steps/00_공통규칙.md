# 공통 규칙 (모든 단계에서 지킬 것)

## 기준
- 화면 모양과 동작은 `design/*.dc.html` 시안이 기준이다. 이 문서와 시안이 다르면 시안을 따른다. 시안 HTML은 참고용이며 그대로 복사해 쓰지 않는다.
- 시안을 볼 때: 각 파일의 `<x-dc>` 안이 화면 마크업, `class Component` 안이 동작이다. 브라우저로 열면 실제로 눌러 볼 수 있다(같은 폴더의 support.js, _ds 필요).

## 화면 크기
- 폭 700px 이상 = 컴퓨터, 700px 미만 = 폰.
- 컴퓨터: 모든 화면이 **같은 크기·같은 위치의 펼친 책** 한 권 안에서 나타난다.
  - 책 높이 BH = min(750, 창 높이 − 110), 책 폭 BW = min(1100, 창 폭 − 130, BH × 1.6). 화면에 고정(position: fixed), 책 본체가 화면 가운데.
  - 첫 화면 표지를 펼친 크기도 이 크기와 같다.
  - 책 오른쪽에 가죽 탭 3개(학습 / 테스트 / 마이페이지). 탭은 책 오른쪽 **세로 직선 부분**에만 닿고 위아래 둥근 모서리에는 닿지 않는다. 탭 전체 길이 = 직선 부분 길이.
  - 탭과 책 테두리는 어떤 화면(학습 중, 테스트 중 포함)에서도 크기·위치가 바뀌거나 사라지지 않는다.
  - 아무것도 책 틀 밖으로 나가지 않는다. 화면 이름 글자도 책 안에 둔다. 넘치면 쪽 안에서 스크롤(스크롤바 숨김).
  - 가운데 접힌 곳 가까이는 비워 둔다(쪽 안쪽 여백을 넉넉히).
- 폰: 화면 전체가 책 한 쪽. 화면 가장자리에 가죽 테두리 + 금박 선, 아래에 가죽 탭바(지금 탭만 종이색). 카메라·노치 자리는 safe-area로 비운다. 안쪽 칸은 테두리 없이 옅은 바탕만.
- 폰 문제 풀이 화면(단어·문법·문장 학습, 테스트): 문제 카드는 책 테두리 없이 깔끔한 문제지 — 바탕 #fffdf8, 1px #e8dcc6 테두리, 둥근 모서리 22px, 옅은 그림자(0 1px 2px rgba(46,43,37,.05), 0 12px 28px -18px rgba(46,43,37,.28)). 좌우 여백을 같게 해서 화면 가운데에 둔다. 스크롤바는 숨긴다(스크롤바 폭만큼 내용이 왼쪽으로 밀리지 않게).

## 학습 화면 공통 틀 (단어·문법·문장)
- 왼쪽 쪽 맨 위: ← 뒤로 화살표 + "3과 | 단어"(과 번호는 제목 글꼴·테라코타). 그 아래 문제.
- 오른쪽 쪽: 보기, 다음 버튼, 맨 아래 "문항 진행 N / M"과 진행 점. 폰은 진행 점 없이 오른쪽 위에 N / M 숫자만.
- 정답을 골라도 문제·보기·진행 표시가 **움직이지 않는다**. 다음 버튼 자리는 미리 비워 둔다. 다음 버튼은 보기가 있는 쪽, 문제지 바로 아래.
- 안내 문구 "알맞은 답을 고르세요" 같은 것은 넣지 않는다.
- 진행 수 N: **완전히 통과해서 다시 안 볼 문항**만 센다. 진행 점은 처음 답한 순서로 칠하고(맞음 세이지, 틀림 빨강), 지금 문항은 주황 테두리.
- 틀린 문항은 회차 끝에 다시 나온다(문제 위 "다시 풀기" 표시). 맞힐 때까지 반복.
- 틀리면 "오답 노트에 담았어요" 알림이 위로 쓱 올라가며 사라진다.
- 책갈피(저장): 문제 카드 오른쪽 위 끈. 누르면 끈이 길어지고 진해지며 저장, 다시 누르면 빠짐. 끈 옆 안내 "끈을 내리면 책갈피에 담겨요" / "책갈피에 담았어요". 누르는 범위는 끈보다 넓게(좌우 40px, 아래 24px).
- 나가기: ← 또는 오른쪽 탭을 누르면 경고 팝업. 학습은 "지금까지 푼 곳은 저장돼서 이어서 할 수 있어요." 다음 줄에 빨간 굵은 글씨 "경험치와 학습 기록은 끝까지 마쳐야 남습니다." 테스트는 "지금 나가면 이번 테스트의 경험치와 기록이 남지 않습니다."(빨간 굵게) + "틀린 문항은 오답 노트에 남고, 다시 시작하면 처음부터 풉니다."
- 이어서 하기: 학습만(7일 보관). 테스트는 항상 처음부터.

## 기록 규칙
- 오답 노트: 한 회차에서 한 문항은 한 번만 센다. 다른 회차에서 연속 2번 한 번에 맞히면 오답 노트에서 빠진다(졸업).
- 오늘의 목표: 단어·문법·문장 종류별 목표. 학습에서 문항이 통과될 때 +1, 테스트에서 한 번에 맞힐 때 +1(플래시 카드는 단어). 매일 0시(사용자 시간대)에 새로 시작. "매일 0시에 초기화" 안내는 목표 수정 팝업에만.
- 경험치·학습 기록·소요 시간: 회차를 끝까지 마쳤을 때만 저장.
- 저장 위치: Supabase(`db/schema.sql`). 표와 규칙 설명은 `db/user_db.xlsx`.

## 콘텐츠
- `data/lessons.json`: 26과 제목, ready(3~8과). 준비 안 된 과는 목차에서 눌러도 "준비 중".
- `data/lNN.json`: words, grammarLearning(문법 학습용), grammarQuestions(테스트용), sentences(각 문장에 parsing 포함), parsingExtra, concepts(문법 개념 표).
- 보기 answer는 0~3 번호. 파싱 약어는 `data/codes.json`으로 한국어 표시.
- 단어 참조는 과를 넘는다(제4과 문장이 제3과 단어를 가리킴). 모든 과 단어를 한꺼번에 불러 id로 찾는다.

## 빠진 기능 (만들지 말 것, 나중 후보)
상점·아이템, 화면 모드(다크)·테마, 언어 선택, 효과음, 랭킹·친구·초대 코드, 연속 학습 표시, 로그인 없이 둘러보기, 학습 알림(가입 화면 알림 동의 포함), 마이페이지 이름 입력 칸.
