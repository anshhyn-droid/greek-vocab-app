# 3단계 · 책 표지 첫 화면과 Google 로그인

아래 블록을 복사해 Antigravity 에이전트에 붙여넣으세요.

```text
3단계: 책 표지 첫 화면과 Google 로그인

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Start.dc.html(시작 화면·계정 선택·약관), db/schema.sql, db/보안_개인정보_명세.md

할 일
1. Supabase 연결: .env에 VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY 자리를 만들고 클라이언트를 만든다. db/schema.sql을 Supabase SQL 편집기에 넣는 방법을 README에 적는다.
2. 첫 화면 = 닫힌 책 표지(펼친 책 크기의 한 쪽). 표지에 "눌러서 펼치기". 누르면 표지가 왼쪽으로 넘어가며 열리고(약 1.5초), 첫 장에 ΛΟΓΟΣ와 "Google로 계속하기" 버튼. 열린 책을 다시 누르면 닫힌다(버튼 클릭은 책 닫기로 전달되지 않게).
3. Google 로그인(Supabase OAuth). 처음 가입이면 약관 동의 창: 만 14세 이상·이용약관·개인정보 수집·이용(모두 필수, "모두 동의" 포함). 동의는 user_consents에 저장. 학습 알림 동의는 넣지 않는다.
4. 가입 후 users, user_settings, user_goals 기본 행을 만든다.
5. 자동 로그아웃: 마지막 활동 후 24시간이 지나면 로그아웃, 다음 접속 때 첫 화면에 "하루 동안 사용하지 않아 로그아웃되었어요" 안내. 활동 시각은 클릭·키 입력 때 갱신.
6. 로그아웃하면 기기(localStorage)에 남은 학습 정보를 지운다.
7. 로그인 상태면 첫 화면 대신 학습 홈으로 간다.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```

## 완료 확인
- [ ] 표지 → 펼치기 → Google로 계속하기 → 계정 선택 → 모두 동의 → 학습 홈까지 간다
- [ ] 펼친 책 위의 버튼을 눌러도 책이 닫히지 않는다
- [ ] Supabase에서 users·user_consents 행이 생긴다
- [ ] last_active를 25시간 전으로 바꾸면 안내와 함께 로그아웃된다
