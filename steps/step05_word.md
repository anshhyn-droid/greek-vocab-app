```text
5단계: 단어 학습

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Word Study.dc.html, design/xp-fly.js, design/gk-notes.js, design/gk-session.js

할 일
1. 왼쪽 쪽: 헬라어 단어 크게(가운데 정렬), 단어 바로 위에 남은 시간 표시(위치 고정 — 시간이 나타나고 사라져도 단어가 안 움직임). 단어와 오른쪽 보기의 세로 중심을 맞춘다.
2. 오른쪽 쪽: 뜻 보기 4개(컴퓨터는 세로 한 줄씩, 폰은 2×2), 보기 아래 다음 버튼 자리, 맨 아래 문항 진행(단계가 바뀌어도 진행 표시 위치 고정).
3. 흐름은 시안 그대로: 단어 보여 주기 → 보기 고르기. 바퀴 2번(1바퀴: 뜻 보고, 2바퀴: 뜻 없이). 오답은 흐리게, 정답은 세이지.
4. 책갈피 끈, 오답 노트 알림, 나가기 경고, 이어서 하기(study_runs.queue·extra_state 저장)를 공통 규칙대로.
5. 끝나면 결과(소요 시간, 한 번에 맞힌 수, 경험치) + 경험치 모션(design/xp-fly.js 참고) 후 daily_activity·lesson_progress 저장.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```
