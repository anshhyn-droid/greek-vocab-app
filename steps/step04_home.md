# 4단계 · 학습 홈과 과 메뉴

아래 블록을 복사해 Antigravity 에이전트에 붙여넣으세요.

```text
4단계: 학습 홈과 과 메뉴

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Start.dc.html(학습 홈), design/Lesson Menu.dc.html, design/Phone Preview.dc.html

할 일
1. 학습 홈 왼쪽 쪽: 가죽 책갈피(지금 할 과 · "3과" · 이어서 학습하기 →). 책갈피 길이는 옆의 과 이름과 단어·문법·문장 줄 높이에 맞춘다. 단어·문법·문장 줄은 점선으로 이어진 진도(완료=세이지 ✓, 진행 중=작은 책갈피, 이어서 할 것은 '이어서'). 줄을 누르면 그 학습으로 바로 간다.
2. 책갈피 아래: 오늘의 목표 자세히(전체 막대 + 단어·문법·문장 줄마다 막대와 "4 / 8", 다 채우면 세이지). "수정"을 누르면 팝업에서 종류별 목표를 바꾸고, 팝업에만 "매일 0시에 새로 시작" 안내.
3. 오른쪽 쪽: 목차 26과. 스크롤하며 한 줄씩 본다. 줄마다 과 번호·제목·단어/문법/문장 세 칸 점선 진도·끝 표시. 지금 할 과 강조. 준비 안 된 과는 흐리게.
4. 과 메뉴(과를 누르면): 3과 제목, 단어·문법·문장 칸. 진행 중이면 '이어서', 안 했으면 '다음/시작', 끝났으면 완료. 맨 아래 별도 '이어서' 버튼은 두지 않는다.
5. 폰: 맨 위 오늘의 목표 → 책갈피가 달린 지금 할 과 칸 → 목차.
6. 진도·목표 값은 Supabase(lesson_progress, daily_activity, user_goals, study_runs)에서 읽는다.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```

## 완료 확인
- [ ] 단어·문법·문장 줄을 누르면 바로 그 학습이 열린다
- [ ] 목표를 바꾸면 막대와 숫자가 바로 바뀐다
- [ ] 목차가 책 안에서만 스크롤된다
- [ ] 폰에서 오늘의 목표가 맨 위에 있다
