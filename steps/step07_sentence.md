# 7단계 · 문장 학습

아래 블록을 복사해 Antigravity 에이전트에 붙여넣으세요.

```text
7단계: 문장 학습

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Sentence Study.dc.html, data/codes.json

할 일 (문장 학습 = 해석 블록 맞추기 + 동사 파싱. 자세한 규칙은 design/문장학습_명세.md — 화면 배치는 공통 규칙의 책 틀이 우선)
1. 왼쪽 쪽: "제3과 N번 문장" 태그, 헬라어 문장(크게), 그 아래 해석 블록 맞추기. 정답_번역을 띄어쓰기로 나눈 낱말 + 함정 낱말 2~3개를 섞어 보여 준다. 누르거나 끌어서 해석 칸에 넣고, 칸 안에서 끌면 순서만 바뀌고, 칸 밖으로 끌면 빠진다. 어순은 채점하지 않는다.
2. 오른쪽 쪽: 동사 파싱 카드(문장의 parsing 행마다 1장). 원형·시제·태·법·수·인칭 여섯 줄을 순서 없이 고른다(codes.json으로 한국어). 원형을 맞히면 "← 기본형 · 뜻"이 나타나고, 여섯 줄을 다 맞히면 그 동사의 해석(gloss)이 나온다.
3. 확인 버튼은 하나: 해석 칸에 낱말이 1개 이상 있고 모든 파싱 줄을 골랐을 때만 눌린다. 틀린 낱말은 빠지며 취소선으로 잠기고, 틀린 파싱 보기는 빨강 → 다른 보기를 고르면 회색으로 잠긴다.
4. 해석이나 파싱을 한 번이라도 틀리면 그 문장은 맨 뒤로 가서 다시 나온다(다시 풀기). 모두 맞히면 비고(note) 설명 + "다음 문장".
5. 책갈피(sent), 나가기, 이어서 하기, 결과·경험치는 공통 규칙대로. 폰은 왼쪽 쪽 → 오른쪽 쪽 순서로 위아래.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```

- [ ] 제8과 문장처럼 미래·수동태·디포넌트도 한국어로 표시된다
- [ ] 틀린 문장이 끝에 다시 나온다
