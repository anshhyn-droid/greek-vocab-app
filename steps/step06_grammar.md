# 6단계 · 문법 학습

아래 블록을 복사해 Antigravity 에이전트에 붙여넣으세요.

```text
6단계: 문법 학습

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Grammar Study.dc.html, data/lNN.json의 concepts·grammarLearning

할 일
1. 시작: 개념 정리 화면. 맨 위 "← 3과 | 문법 정리" 한 줄만(제목 두 번 쓰지 않음). 두 쪽에 concepts 표를 나눠 싣고, 나란히 놓인 표끼리 높이를 맞춘다. 넘치면 쪽 안에서 스크롤. 이때는 문항 진행을 보여 주지 않는다. 오른쪽 쪽 위에 "문제 풀기" 버튼(위아래 여유 있게).
2. 문제: grammarLearning 전부를 낸다. 왼쪽 쪽에 문제(prompt, target_form 강조), 오른쪽 쪽에 보기 4개(옅은 바탕 칸, 번호는 제목 글꼴)와 해설·다음 버튼, 맨 아래 문항 진행.
3. "개념 보기"를 누르면 왼쪽 쪽 아래 빈 곳에 개념 표가 펼쳐진다.
4. 책갈피: 문제(gram)와 개념 표(concept, id 예: L03-1) 둘 다 담을 수 있다.
5. 나머지 규칙(다시 풀기, 오답 노트, 나가기, 이어서 하기, 결과·경험치)은 공통 규칙대로.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```
