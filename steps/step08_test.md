# 8단계 · 테스트 탭

아래 블록을 복사해 Antigravity 에이전트에 붙여넣으세요.

```text
8단계: 테스트 탭

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Review.dc.html

테스트는 설명 없이 빠르게 외우는 곳이다.
할 일
1. 왼쪽 쪽 위에 색인 탭 3개: 테스트 / 오답 노트(개수) / 책갈피(개수). 탭과 내용은 모두 책 안. 설명은 왼쪽 쪽, 문항 목록은 오른쪽 쪽에 따로.
2. 테스트 설정: 설명 "설명 없이 문제만 빠르게 넘기며 외웁니다."(두 줄 이내), 종류(단어·플래시 카드·문법·문장), 과 선택(ready 과만), 책갈피만 켜기, 오답 먼저. 스크롤 없이 한 화면에 들어간다. 문항 수 20.
3. 문제: 문법은 grammarQuestions에서 무작위 20개. 학습 화면과 같은 틀(왼쪽 문제, 오른쪽 보기·진행). 단어 테스트는 정답을 고르면 0.65초 뒤 자동으로 다음 문제(다음 버튼 없음). 문법·문장은 다음 버튼. 문장 테스트는 블록 맞추기 없이 "해석 보기"를 누르면 정답 번역 전체가 보이고, 동사 파싱(여섯 줄 고르기)에 중점을 둔다.
4. 플래시 카드: 눌러서 뒤집고 앎/모름.
5. 오답 노트: 왼쪽에 설명·개수, 오른쪽에 틀린 문항 목록(과·틀린 횟수). 오답만 다시 풀기.
6. 책갈피: 담은 단어·문법·문장·개념 표 목록. 개념 표는 눌러서 표를 다시 본다.
7. 테스트에서 한 번에 맞힌 문항은 오늘의 목표에 더한다. 끝나면 경험치·기록 저장. 중간에 나가면 abandoned.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```

## 완료 확인
- [ ] 단어 테스트에서 정답을 고르면 자동으로 넘어간다
- [ ] 테스트에서 틀린 문항이 오답 노트에 남는다
- [ ] 오답 노트·책갈피 목록이 오른쪽 쪽에 나온다
- [ ] 테스트 설정 화면에 스크롤이 생기지 않는다
