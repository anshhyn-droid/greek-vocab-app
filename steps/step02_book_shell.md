# 2단계 · 펼친 책 틀과 탭

아래 블록을 복사해 Antigravity 에이전트에 붙여넣으세요.

```text
2단계: 펼친 책 틀과 탭

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Start.dc.html, design/Lesson Menu.dc.html, design/Phone Preview.dc.html

할 일
1. BookShell 컴포넌트: 공통 규칙의 공식으로 책 크기를 계산해 화면 가운데에 고정한다. 가죽 테두리 13px, 금박 선, 종이 그라데이션, 가운데 접힌 곳 그림자. 왼쪽 쪽·오른쪽 쪽 두 칸(slot)을 받는다. 쪽 비율은 화면마다 props로 바꿀 수 있게 한다.
2. 오른쪽 가죽 탭 3개(학습/테스트/마이페이지): 책 오른쪽 직선 부분에 딱 붙고, 지금 탭은 종이색으로 책 안과 이어져 보인다. 어떤 화면에서도 같은 자리.
3. 폰(700px 미만): PhonePage(화면 전체 한 쪽 + 가장자리 가죽·금박) + 하단 가죽 탭바. safe-area 처리.
4. 창 크기가 바뀌면 다시 계산한다. 넘치는 내용은 쪽 안에서 스크롤(스크롤바 숨김).
5. 빈 화면 3개(학습/테스트/마이페이지)에 이 틀을 씌우고 탭으로 오간다.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```

## 완료 확인
- [ ] 창 크기를 바꿔도 책 비율이 BW ≤ BH×1.6을 지킨다
- [ ] 세 탭을 오가도 책·탭 위치가 1px도 안 움직인다
- [ ] 폰 폭에서 하단 탭바와 화면 테두리가 보이고 노치에 안 가린다
