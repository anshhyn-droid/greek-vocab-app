# 9단계 · 마이페이지와 마무리

아래 블록을 복사해 Antigravity 에이전트에 붙여넣으세요.

```text
9단계: 마이페이지와 마무리

먼저 steps/00_공통규칙.md를 끝까지 읽고 지켜 줘.
참고할 파일: design/Start.dc.html(마이페이지·학습 기록), design/xp-fly.js, db/사용자_DB.xlsx

할 일
1. 마이페이지: 왼쪽 쪽 = 학습 기록(누적 경험치, 학습한 날, 최근 7일 경험치 막대, 과별 진도), 오른쪽 쪽 = 설정(계정: 이름·이메일 앞 두 글자만, 로그아웃 / 글자 크기 m·l·xl / 학습 기록 초기화 / 회원 탈퇴). 오른쪽 쪽은 가운데 접힌 곳에서 떨어지게 여백.
2. 학습 기록 초기화: 두 번 눌러야 실행. 경험치·기록·진도·오답 노트·책갈피·이어서 하기·오늘 진행 삭제, 계정·설정·동의는 남김.
3. 회원 탈퇴: 확인 창(지워지는 것, 되돌릴 수 없음) 후 auth 사용자 삭제(서버 함수) → 모든 표 cascade 삭제 → 첫 화면.
4. 경험치 모션: 결과 화면에서 경험치가 오른쪽 탭 쪽으로 날아가 쌓이는 모션(xp-fly.js 동작 그대로).
5. 최종 점검: 컴퓨터(1280×800, 924×540)와 폰(390×844)에서 모든 화면을 열어 책 틀 밖으로 나가는 것, 글자 줄바꿈 꺾임("3 / 과" 같은), 겹침이 없는지 확인하고 고친다.

끝나면 아래 "완료 확인"을 직접 확인하고, 바꾼 파일 목록과 확인 결과를 알려 줘.
```
