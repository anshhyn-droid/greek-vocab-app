## 5. 미래 접사 -σ-에 따른 자음 변화

| 어근 끝 자음 | 변화 | 기본형 → 미래형 | 뜻 |
| --- | --- | --- | --- |
| 구개음 γ, κ, χ | γ/κ/χ + σ → ξ | ἄγω → ἄξω | 인도하다 |
| 구개음 γ, κ, χ | γ/κ/χ + σ → ξ | διδάσκω → διδάξω | 가르치다 |
| 구개음 γ, κ, χ | γ/κ/χ + σ → ξ | κηρύσσω → κηρύξω | 선포하다 |
| 양순음 β, π, φ | β/π/φ + σ → ψ | γράφω → γράψω | 쓰다 |
| 양순음 β, π, φ | β/π/φ + σ → ψ | πέμπω → πέμψω | 보내다 |
| 치조음 δ, τ, θ, ζ | 끝 자음 탈락 + σ | πείθω → πείσω | 설득하다 |
| 치조음 δ, τ, θ, ζ | 끝 자음 탈락 + σ | ἐλπίζω → ἐλπίσω | 소망하다 |
